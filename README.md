# 🧠 Mastermind Python Game
A simple game which aims to replicate the Mastermind board game. Mastermind or Master Mind is a code-breaking game for two players; one player setting a code and forming responses and the other guessing the code by forming their own colour sequences.

## 🕹️ How To Play
When a game is started, the player will be shown an empty board along with a guide on which colours are accepted for the round and a prompt to enter your desired combination of colours. Here are the rules for entering colour combinations:
- Each colour must be seperated by a space or punctuation.
- Each colour must be the exact two letters stated in guide before the input prompt.
- Can be lower/uppercase.
- Must contain the same number of colours as there are columns on the board.
- Attempts are submitted by pressing the 'Enter' key.
After each attempt is submitted, the player will receive a sequence of solid dots, hollow dots and empty spaces. The position of these dots is not related to the correct colour sequence.
- Solid dot: Correct colour in the correct position
- Hollow dot: Correct colour but in the wrong position
- Empty: Wrong colour
