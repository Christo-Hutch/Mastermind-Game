# 🧠 Mastermind Python Game
A simple game which aims to replicate the Mastermind board game. Mastermind or Master Mind is a code-breaking game for two players; one player setting a code and forming responses and the other guessing the code by forming their own colour sequences.

## 📲 Installation
### 🪟 Windows
1) Download the latest **Windows** release executable.
2) Double-click on the downloaded file in your file explorer.

### 🍎 MacOS
1) Download the latest **MacOS** release executable.
2) Run this command: `chmod +x {path-to-downloaded-file}`
3) Run this command: `./{file-name}`

### 🐧 Linux
1) Download the latest **Linux** release executable.
2) Run this command: `cd {path-to-download-folder}`
3) Run this command: `chmod +x {file-name}`
4) Run this command: `./{file-name}`
